# Модуль 8 — Капстоун: детализация

*Спутник «Модуля 8». Кода здесь почти нет — всё построено в М2–М7; капстоун — сборка, приёмка и доказательства. Новая работа — интеграционная и документальная, и она труднее, чем кажется.*

## 8.1 Сборка сквозного сценария (гл. 26)

Целевой поток одного обращения:

```
пользователь → шлюз (М6: аутентификация, квота, маршрутизация §6.7, PII на выходе §6.8)
   → агент (М4: харнесс, бюджеты, детекция прогресса)
      → ретрив (М3: hybrid + rerank, RLS по Keycloak-ролям)
      → инструменты по MCP (М5: скоупы, token exchange)
      → human-gate (М4) на createTicket и любой записи
   → ответ + полная трасса в Langfuse (М6)
```

Порядок сборки — от шлюза внутрь (каждый шаг проверяется своим смоуком из соответствующего модуля):
1. Все клиенты — через шлюз (М6 DoD уже требовал; проверь, что ничего не отвалилось).
2. Агент М4 получает инструменты *только* через свой MCP-клиент к серверу М5 (§5.1 уже перевёл харнесс на него; проверь на сборке, что прямых вызовов сервисов не осталось — иначе скоупы и пиннинг ничего не защищают).
3. RLS-контекст течёт от JWT пользователя через token exchange до SQL (`SET LOCAL`) — проверь трассой, что clearance в спане совпадает с ролью.
4. Human-gate стоит на всех необратимых инструментах (маркируй их в описании — как `createTicket` в М5 — и заведи автотест «необратимый инструмент без гейта не вызывается»).
5. Опционально: экстрактор полей из М7 (через vLLM или заранее снятые результаты) — как дешёвый первый шаг конвейера классификации.

## 8.2 Приёмка №1: пре-флайт чек-лист (Приложение D)

Пройди все 27 пунктов. Правила честности:
- пункт закрыт = есть **артефакт** (тест, дашборд, конфиг, документ) — «сделано в голове» не считается;

## 8.3 Приёмка №2: своё «Приложение C»

Сними полную трассу одного репрезентативного диалога (2–3 хода с ретривом, инструментом и гейтом):
1. **Sequence-поток** — по спанам Langfuse восстанови диаграмму уровня Приложения C (mermaid).
2. **Дерево спанов** — скриншот/экспорт с длительностями.
3. **Таблица токенов и стоимости по ходам** — вход/выход/кэшированные, стоимость каждого вызова, итого на диалог.

Сравни с эталоном книги: где твой диалог дороже или медленнее (у эталона ~$0.0065 и turn-1 ≈ 7.8 с — твои числа будут другими, интересно *почему*: другая модель? нет кэша? лишний ход агента?). Разница, которую ты можешь объяснить, — признак понимания; разница, которую не можешь, — материал для разбора.

## 8.5 Финальный прогон

1. **Red-team М6 целиком** против собранной системы (не компонентов) — атаки из §6.4 плюс одна новая, придуманная под свою сборку (композиция «MCP-инструмент + гейт + ретрив»).
2. **Eval-гейт** зелёный на всех наборах (М3 вопросы, М4 инструменты).
3. **Хаос М4** на собранной саге — оба сценария.
4. День «эксплуатации»: 30–50 разнообразных запросов, вечером — разбор дашбордов (стоимость/пользователь, доля маршрутов, метрики гейта) как продакшен-ревью.
